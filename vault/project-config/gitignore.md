# .gitignore

## What it does
מחריג קבצים רגישים מה-git. כרגע מחריג אך ורק את `.env` כדי שמפתחות API לא ייכנסו ל-repository.

## Associated with
- [[env-config]] — `.env` הוא הקובץ שמוחרג

## Notes
יש להוסיף כאן קבצים נוספים כשהפרויקט יגדל (node_modules, __pycache__, וכד').
