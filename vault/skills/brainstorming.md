# Skill: brainstorming

## What it does
מחייב עיצוב ואישור משתמש **לפני** כל קוד. מנחה דיאלוג מובנה: הבנת הרעיון ← שאלות הבהרה ← 2-3 גישות ← הצגת עיצוב ← כתיבת spec ← מעבר ל-writing-plans. HARD-GATE: אסור להתחיל קוד לפני אישור.
