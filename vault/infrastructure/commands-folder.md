# .claude/commands/

## What it does
תיקייה שתכיל slash commands מותאמים לפרויקט — קיצורי דרך שניתן לקרוא להם ב-Claude Code עם `/command-name`. כרגע ריקה (רק `.gitkeep`), תמולא עם התפתחות הפרויקט.

## Associated with
- [[claude-md]] — CLAUDE.md מפנה לתיקייה זו
- [[skills-folder]] — commands לרוב מפעילים סקילים

## Notes
כל command הוא קובץ MD עם הגדרת הפקודה. אל תדרוס — תיקייה זו שייכת לפרויקט.
