# .claude/agents/

## What it does
תיקייה שתכיל הגדרות sub-agents מותאמות לפרויקט — כל agent יוגדר בקובץ MD עם system prompt, כלים זמינים, והרשאות. כרגע ריקה (רק `.gitkeep`), תמולא בהתאם לארכיטקטורת הסוכנים שתוגדר.

## Associated with
- [[claude-md]] — CLAUDE.md מפנה לתיקייה זו
- [[skills-folder]] — agents יכולים להשתמש בסקילים מ-.claude/skills/
- [[commands-folder]] — agents יכולים לקרוא slash commands

## Notes
תיקייה זו שייכת לפרויקט ולא ל-superpowers. אל תדרוס תכנים ידנית — נוספים רק על ידי המשתמש.
