# Skill: test-driven-development

## What it does
מחייב כתיבת בדיקה **לפני** קוד המימוש. מחזור: כתוב בדיקה → ראה שנכשלת → כתוב קוד מינימלי → ראה שעוברת → refactor. sub-agents צריכים לעקוב אחרי TDD לכל task. כולל רשימת anti-patterns נפוצות.
