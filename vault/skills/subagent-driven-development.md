# Skill: subagent-driven-development

## What it does
מבצע תכנית מימוש בסשן הנוכחי על ידי שליחת sub-agent נפרד לכל task. אחרי כל task — ביקורת כפולה: (1) spec compliance reviewer, (2) code quality reviewer. ממשיך ברציפות ללא עצירות מיותרות.
