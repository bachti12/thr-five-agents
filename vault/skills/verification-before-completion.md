# Skill: verification-before-completion

## What it does
מחייב הרצת פקודות אימות ואישור output **לפני** כל הכרזה שהעבודה הסתיימה. אסור לומר "הבדיקות עוברות" בלי להריץ אותן ולראות את התוצאה. ראיות לפני טענות — תמיד.
